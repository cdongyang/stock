核心：跟着庄家操作，庄家压价买入时，*控制个人买入价格比庄家平均价格低*，庄家拉高出货时跟着出

用电脑看 K 线，设置 5 秒间隔，看得更细，看到得数据更多

*买入：*
庄家快速拉高价格出货时，可以在价格降到低点向上拐时买两倍做多，市价购买可以避免固定价格买不到
庄家拉高价格出货时，可能触发空头回补，然后一直涨，空头不断回补，庄家偷偷出货，这时可以两倍做多，一旦达到拐点向下马上市价卖出
庄家快速买入拉高，然后快速卖出一次性把昨天的货都出完了，价格开始慢慢降下去（这时候可以考虑卖空），庄家又慢慢进货

*卖出：*
庄家快速拉低价格进货时，可以在价格涨到高点往下降时买两倍做空，市价购买可以避免固定价格买不到

*买入/卖出：*
庄家拉低价格进货时，如果某个价格挂单太多，庄家很可能不愿意砸穿这个价格，成本太高，这个价格高一点就是比较安全的做多价格，一旦被砸穿马上市价卖出；庄家可能会把价格打到这个点位，慢慢磨，让散户将这个价格打穿

*禁忌：*
庄家小波动横盘收货时，先观察挂盘的卖出和买入价格差，如果价格相差较多，不要买两倍做多/做空，如果波动不大很可能会亏
做空不要过夜，比较危险
买了两倍做空，持续上涨时要尽快割，越等可能亏损越多

*操作*
庄家还没出完货时，高于庄家平均价格，价格下降时可以再等等
庄家接近出完货时，高于庄家平均价格，不要再进场了

## 判断
- 开场的预判可能出错，可以在庄家磨盘进货时频繁做 T，1.5% 左右上下波动买入卖出（更安全）
- 横盘一段时间后，可以挂一个横盘点低 1.5% 左右的买点，庄家可能会下探看是否触发止损单
- 卖出横盘一段时间后可以挂一个横盘点高 1.5% 左右的卖单，庄家可能会上探看是否触发空头止损单
- 逼空第一次顶点一般是昨天的开盘价，如果能顶开高峰继续触发空单止损就能连前一天的一起逼空，所以可以先在这个顶点卖一半左右确认收益，留一半赌一下逼空
- 庄家可能隔空在某个点位将大量挂单买入/卖出，然后不会引起价格大动，当其它人发现时，马上价格剧烈波动，庄家可能在卖出的点位再磨盘收回筹码，甚至更低一点的点位，*在庄家卖出的价格卖出是比较安全的*，更低价格的时候也可以再买入，更低卖出拉上来之后可能就难买回了
- 11:30 之后再买入第二笔，容错性强一些，如果庄家调转，还能平均一下买入价，减少亏损

⏺ 主动买入判断规则                                                                                                                     

  成交价 vs 卖一价比较：                                                                                                               

- 成交价 ≥ 卖一价 → 买方主动扫单 → 主动买入（流入）                                                                                  
- 成交价 ≤ 买一价 → 卖方主动砸单 → 主动卖出（流出）                                                                                  
- 成交价在买一卖一之间 → 方向不明（通常归入上一笔方向）

  举例                                                                                                                                 

  某时刻盘口：买一 100.0，卖一 100.2

  ├──────────┼────────┼────────┼───────────────────────────────────────┤  
  │ 10:00:01 │ 100.2  │ 1000   │ 成交价=卖一 → 主动买入                │
  ├──────────┼────────┼────────┼───────────────────────────────────────┤
  │ 10:00:02 │ 100.0  │ 500    │ 成交价=买一 → 主动卖出                │  
  ├──────────┼────────┼────────┼───────────────────────────────────────┤  
  │ 10:00:03 │ 100.1  │ 200    │ 介于中间 → 沿用上一笔方向（主动卖出） │  
  ├──────────┼────────┼────────┼───────────────────────────────────────┤  
  │ 10:00:04 │ 100.3  │ 800    │ 成交价>卖一 → 主动买入（扫穿卖一）    │
  └──────────┴────────┴────────┴───────────────────────────────────────┘   

*庄家如果挂了大量买单的话，买入是不会显示在净买入里面的，然后就可以偷偷进货，后面再拉升出货*
最好的入场时机是价格低于庄家平均价的时候，如果在庄家拉升出货的时候一直等，等到庄家出完就可能砸盘了，适当点位该卖出就卖出
如果不好判断庄家的平均价格，看 VWAP（成交量加权平均线）进行判断，卖出高于平均线，买入低于平均线

对倒出货:
庄家用两个账户互相交易——A账户卖、B账户买，制造成交量但价格不动。净卖出数据显示的是账户归属变化，但价格被人为维稳。同时慢慢把筹码转移给外部散户。

  - Securities Exchange Act of 1934, Section 9(a)(1)：明确禁止 wash trading（无真实所有权转移的自买自卖）
