# 技术分析经验

## 净流入与股价背离：派发阶段识别

### 模式描述

| 阶段 | 净流入 | 价格 | 含义 |
|------|--------|------|------|
| ① | 快速升高 | 快速拉升 | 主力拉抬建仓完成后推价 |
| ② | 缓慢降低 | 波动不大 | ⚠️ 疑似派发阶段 |
| ③ | 趋近于零 | 横盘 | 主力卖盘与散户买盘对冲 |
| ④ | 转负 | 开始下跌 | 派发完成，主力出局确认 |

### 核心逻辑

阶段②价格稳住的原因：**主力用散户的持续买盘作为出货接盘方**，价格维持是为了维持"安全"假象，吸引更多追高资金。

### 不一定是出货的情况

- **正常缩量整理**：净流入降低 + 成交量同步萎缩 + 小区间横盘 + 无大卖单 → 健康整理
- **机构换手**：净流入降低但换手率高，不同机构轮动 → 性质中性

### 出货概率更高的佐证信号

1. **量价背离**：成交量大但价格涨不动（冲高乏力）
2. **上影线频繁**：每次拉高都被压回，高位持续有卖压
3. **净流出后补跌**：净流入降低阶段随后出现净流出 + 放量下跌，印证之前已在出货
4. **龙虎榜 / 大宗交易**：机构席位大量卖出记录

### 对应框架

与 **Wyckoff 派发结构**高度吻合：
- PSY（初步供给）→ BC（买入高潮）→ AR（自动回调）→ UT（向上突破假动作）→ 最终下跌

### 操作结论

价格稳住期间是"假稳"还是"真整理"，需等净流入继续萎缩转负 + 随后放量下跌来**事后验证**。不宜在阶段②单独依此做空，需结合量价、上影线、龙虎榜综合判断。

## 控盘拉升：供给垄断与定价权

### 标准路径

```
散户恐慌卖出 → 机构低位接筹 → 控制流通浮筹
→ 限制供给 → 需求触发 → 价格被动抬升 → 机构卖入需求
```

### 核心机制

机构控盘后拥有**供给侧定价权**——流通筹码集中，任何买盘都会放大价格弹性。但定价权要变现，必须有需求侧配合：

| 条件 | 结果 |
|------|------|
| 控盘 + 无需求 | 股价横死，机构同样出不了货 |
| 控盘 + 有需求 | 供给稀缺自动推价，机构顺势卖出 |

### 需求触发器（缺一不可）

- 板块轮动 / 题材热度
- 放量突破引发技术派追涨（FOMO）
- 正面消息 / 业绩催化
- 大盘情绪整体好转

### 关键认知

"散户忍不住追高"是 **稀缺性 × 赚钱效应** 共同驱动的结果，不是机构单方面挂高价就能实现的。

> 机构不是"守着价格等散户来买"，而是先控制供给，再等待/制造需求，需求一来供给稀缺自动推价，最后卖入需求完成出货。

## 逼空行情：用空头的钱出货

### 核心循环

```
庄家拉价 → 空头浮亏 → 被迫平仓买入 → 价格再涨
    ↑                                      ↓
庄家趁机出货 ←←←←←←←←←←←←←←←←←←←←←←←←
    ↓
再低位买回（用空头平仓资金接自己的货）
    ↓
再拉价 → 循环
```

**空头的强制平仓买入 = 庄家出货的接盘方**，庄家不需要等散户，逼空头本身就是在制造需求。

### 价格维持上涨而不崩的原因

| 机制 | 作用 |
|------|------|
| 空头仓位越大，潜在买入力越大 | 空头仓位本质是"预付的买单" |
| 每次拉升触发新的强平 | 形成连续买压，不需要新散户入场 |
| 庄家出货节奏 < 空头平仓速度 | 供给被需求持续吸收，价格不跌 |
| 价格上涨吸引新空头入场 | 做空者越套越多，逼空燃料越来越足 |

### 三个必要条件

1. **空头仓位足够大**：没有空头就没有逼空燃料，高波动小盘股空头比例高天然适合
2. **庄家控盘度足够高**：流通筹码集中，少量买入即可推价
3. **做多叙事存在**：需要让新空头持续敢于入场（负面逻辑越强，空头越多，燃料越足）

### 庄家真实成本结构

```
第一轮：买入 $10 → 拉到 $15 → 出货均价 $14 → 净赚 $4
第二轮：空头强平顶价到 $16 → 庄家 $13 买回 → 再拉到 $20 → 出货 $19
```

每个循环庄家持仓成本下降（空头的钱在帮庄家摊薄），外部看到的却是价格持续上涨。

### 结束信号

- **空头仓位被清空**：没有燃料，行情自然终结
- **庄家出货完毕**：不再需要维持价格
- **放量暴跌**：空头没了只剩追高散户，庄家最后一波砸盘离场

## 庄家完整操盘手段体系

### 一、建仓期（低位吸筹）

| 手段 | 描述 |
|------|------|
| **打压建仓** | 主动砸盘制造恐慌，散户割肉后低位接筹 |
| **横盘磨底** | 长期低位震荡消磨散户耐心，趁悲观情绪吸筹 |
| **跌停板吸筹** | 利用跌停恐慌挂买单，专吃恐慌盘 |
| **对倒建仓** | 左手买右手卖制造虚假成交量，同时低价悄悄吃货 |

### 二、洗盘期（清除浮筹）

| 手段 | 描述 |
|------|------|
| **急跌洗盘** | 吸筹完成后突然快速下砸，逼持仓不稳的散户出局 |
| **消息洗盘** | 配合利空消息放出，制造恐慌后低吸廉价筹码 |
| **长期横盘磨人** | 不跌也不涨，磨到散户失去耐心主动离场 |

> 洗盘 vs 出货的区别：洗盘成交量萎缩、跌幅有限、很快收回；出货成交量放大、反弹无力。

### 三、拉升期

| 手段 | 描述 |
|------|------|
| **控盘拉升** | 控制流通筹码 + 等待催化剂，供给稀缺自动推价 |
| **涨停板效应** | 封涨停制造FOMO，吸引跟风盘次日追入后出货 |
| **逼空拉升** | 利用空头强平买入作为出货接盘，循环推高价格 |
| **对倒拉价** | 自买自卖推高价格，制造放量上涨假象吸引跟风 |

### 四、出货期（高位派发）

| 手段 | 描述 |
|------|------|
| **净流入递减出货** | 价格稳住，净流入缓慢降低，悄悄出货 |
| **高位震荡出货** | 在高位制造反复震荡，每次冲高借散户追高买盘卖出 |
| **利好出货** | 配合重大利好消息公布，借市场兴奋情绪集中出货 |
| **拉高出货** | 尾盘或关键时点突然拉价，吸引追涨后次日高开低走 |
| **阶梯式出货** | 分批在不同价位出货，避免单次大量出货引起警觉 |

### 五、贯穿全程的辅助手段

| 手段 | 描述 |
|------|------|
| **消息配合** | 建仓期放利空、拉升期放利好，节奏与K线精确配合 |
| **技术形态诱导** | 制造头肩底、突破等技术信号，引技术派跟进 |
| **控制节奏** | 涨3天跌1天、每次回调不破关键支撑，让人误以为趋势健康 |

### 各阶段心理控制一句话总结

```
吸筹：让你不敢买（打压/横盘/利空）
洗盘：让你不敢持（急跌/磨人）
拉升：让你不敢空（逼空/FOMO）
出货：让你不敢卖（利好/涨停）
砸盘：让你不得不卖（接力无人，价格崩塌）
```
